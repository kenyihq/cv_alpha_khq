# Kenyi Hancco — Landing CV

Landing page responsive en HTML, CSS y JavaScript vanilla.

## Archivos
- `index.html`: estructura y contenido.
- `styles.css`: diseño responsive y estilos.
- `script.js`: menú móvil y año automático.
- `assets/kenyi-hancco.png`: fotografía de perfil.

## Cómo visualizar
Abre `index.html` en tu navegador. Para publicarlo, sube el contenido de esta carpeta a GitHub Pages, Vercel o cualquier hosting estático.

## Personalización
Revisa especialmente los datos de formación, fechas de experiencia y descripción del reconocimiento de Mesa Clínica antes de publicarlo oficialmente.
